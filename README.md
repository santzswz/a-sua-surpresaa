# Sua surpresa ♥

Site romântico de aniversário, responsivo e feito para GitHub Pages.

- As 10 fotos enviadas estão incorporadas diretamente em `index.html`, então nenhuma lembrança depende de arquivo externo.
- Player incorporado da música **Os Anjos Cantam — Jorge & Mateus**.
- Carta, galeria com ampliação das fotos e seção de presente.
- Links rápidos para lojas virtuais.
- O saldo do presente está mascarado como `R$ ••••` até o valor ser definido.
